Installation details

First installation writes the bootloader, partition table and application. Update writes only the application. Settings from other firmware may not be compatible.

For the VIEWE 7-inch 1024×600 ESP32-P4/C6 display, tested on P4 revision 1.3. The C6 needs compatible ESP-Hosted firmware; this installer does not program it.

If connection fails, hold BOOT, tap RESET, release BOOT, then reconnect.
