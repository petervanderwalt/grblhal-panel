1. Plug in the display

  1. Use desktop Chrome or Edge. Connect a USB data cable to the display’s UART socket.
  2. Close serial monitors and other programs using that port. Disconnect the CNC controller while installing.
  3. Select the display’s CH340 serial port when prompted. If automatic reset fails, hold BOOT, tap RESET, release BOOT, then reconnect.
This build targets the tested early-revision P4 board. It replaces the existing LCD application. The C6 Wi-Fi coprocessor needs compatible ESP-Hosted firmware; this installer does not program the C6.

2. Install the release

Saved Panel settings and the SD card are preserved. A different firmware’s existing settings may not be compatible.
